# Learning Chess With Maizelis

This project is an interactive chess learning application developed by Sajjad Saljoughi. It aims to teach chess from absolute beginner to advanced levels, based on the principles outlined in the book **"Fundamental Chess Theory" by Reuven Fine** (Maizelis is the author/editor of a specific edition or related work, but Reuven Fine is the widely recognized author of "Fundamental Chess Theory").

## 🚀 Features

*   **Interactive Learning:** Comprehensive chess education starting from the very basics to advanced strategies, directly inspired by "Fundamental Chess Theory".
*   **Player vs. Player Mode:** Supports local multiplayer gameplay, allowing two users to play against each other.
*   **Beginner-Friendly:** Designed to guide new players step-by-step through the fundamentals of chess.
*   **Foundation for Advanced Play:** Builds a strong theoretical understanding essential for mastering the game.

## 💡 How to Use

Upon launching the application, you will be greeted by the main menu. From here, you can:

*   **Start Game:** Initiate a game (currently supports Player vs. Player).
*   **Learn Chess:** Begin your chess education journey, guided by the principles from the book.
*   **Settings:** Access application settings (feature to be implemented).

This is an early version, and the menu currently demonstrates the core navigation structure. Further educational content and features will be added progressively.
